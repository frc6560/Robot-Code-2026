# Live Power Dashboard

A live web view of the on-robot power monitor (reads NetworkTables / NT4 directly).

**Windows:** double-click `live-dashboard.bat`
**macOS:** double-click `live-dashboard.command`

It serves this folder locally and opens the dashboard. Enter the roboRIO address
(`10.65.60.2` on the radio, `172.22.11.2` over USB) and click **Connect**. You must be
on the robot's Wi-Fi, and the robot must be running this branch's code. Needs Python installed.
